# Сортировка массива пузырьком (Bubble Sort)

## Описание проекта

Программа на C++, которая позволяет заполнить массив из 10 целых чисел вручную или случайными числами от 1 до 100, а затем отсортировать его по возрастанию с помощью алгоритма пузырьковой сортировки.

## Возможности программы

- Ручной ввод элементов массива.
- Заполнение массива случайными числами от 1 до 100.
- Вывод массива до сортировки.
- Сортировка элементов по возрастанию.
- Вывод массива после сортировки.
- Подсчёт количества обменов элементов во время сортировки.

## Алгоритм сортировки

В программе используется алгоритм **Bubble Sort (пузырьковая сортировка)**.

Принцип работы алгоритма:

1. Программа сравнивает два соседних элемента массива.
2. Если левый элемент больше правого, они меняются местами.
3. После каждого прохода наибольший из ещё не отсортированных элементов оказывается в конце массива.
4. Поэтому при следующем проходе можно проверять меньшее количество элементов, не затрагивая уже отсортированную часть массива.
5. Процесс повторяется, пока не будут выполнены все проходы сортировки.

### Почему количество сравнений уменьшается?

После каждого прохода самое большое из оставшихся чисел перемещается в конец массива. Повторно проверять эти элементы не нужно, поэтому внутренний цикл постепенно сокращается.

В программе это реализовано условием `j < 9 - i`, где `i` — номер прохода, а `j` — индекс элемента, который сравнивается со следующим.

## Подсчёт обменов

Переменная `iter` увеличивается на единицу каждый раз, когда два элемента массива меняются местами.

Таким образом, программа считает **количество обменов**, а не общее количество сравнений или проходов алгоритма.

## Результат работы

В результате выполнения программы пользователь получает массив из 10 целых чисел, отсортированный по возрастанию, и информацию о количестве обменов, выполненных во время сортировки.
